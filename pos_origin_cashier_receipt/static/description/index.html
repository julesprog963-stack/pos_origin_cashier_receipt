Odoo 17 - Point of Sale

POS Origin Cashier Receipt

Imprime el cajero origen en el ticket de POS, con fallback seguro cuando no hay dato.

Compatible con POS + pos_hr

Que hace

  • Agrega una linea "Cashier Origen" en el recibo
  • Usa el campo origin_cashier_id ya existente
  • No altera flujos normales ni devoluciones

Ventajas

  • Herencia limpia de plantilla QWeb
  • Sin cambios al core de Odoo
  • Sin permisos ni ACL adicionales

Instalacion

  • Actualizar la lista de Apps
  • Instalar/Actualizar el modulo
  • Imprimir ticket y validar linea
Nota: requiere el modulo pos_origin_cashier para exponer el cajero origen.
